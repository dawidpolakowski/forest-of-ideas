# 🌲 Forest of Ideas

A futuristic, open repository of ideas for improving games, applications, and digital systems.

This project is designed as a static ideas portal hosted on GitHub Pages — simple, scalable, and easy to expand.

## 🧠 Concept

Forest of Ideas is a structured collection of improvements and feature concepts for:

- 🎮 Games (e.g. MTG Arena)
- 📱 Applications
- 🧩 Digital systems & UX

Each idea is presented as a dedicated page, making it easy to explore, share, and expand.

## 📁 Project Structure
```
forest-of-ideas/
│
├── index.html          # Main dashboard
├── styles.css          # Global styles (futuristic UI)
├── data.js             # Ideas registry
│
├── ideas/              # Individual idea pages
│   └── mtg-arena-improvements.html
│
└── assets/             # Images and media (optional)
```
---

## ⚙️ How It Works

- index.html displays all ideas dynamically from data.js
- Each idea has its own static HTML page
- No backend, no frameworks — fully GitHub Pages compatible

## ➕ Adding a New Idea

1. Create a new HTML file inside /ideas/
2. Add the idea entry in data.js:
```
{
  title: "Your Idea Title",
  file: "ideas/your-file.html",
  category: "Games",
  tags: ["tag1", "tag2"]
}
```
3. Push changes to GitHub

Done — your idea will appear on the homepage.
